Quick heads-up on what Trailmind does

Built for everyday Chrome users

Encrypted Knowledge Graph

Imports your Chrome history into clustered WebGL bubbles and encrypted local snapshots that survive 404 dead links. Never records incognito, passwords, or payment forms.

Ask Memory & Ambient Radar

Press Alt+M on any page to ask questions with cited jumps, and get live on-device alerts when a page contradicts past reading or shows a higher price.

Tab Graveyard Rescue & Journeys

Archive 40+ open tabs into searchable, resumable Chrome Tab-Group Journeys in one click—reclaiming RAM without losing your place.

Transparent Hybrid AI

Per-page reading and sensitive detection stay strictly ONLY_ON_DEVICE. Large multi-week Decision Matrices optionally escalate extracted facts only via Firebase AI Logic + App Check.

Install Trailmind in Chrome (Desktop 139+)

  1. Download the release zip from github.com/Folexy13/trailmind or run npm install && npm run build.
  2. Enable chrome://flags/#prompt-api-for-gemini-nano-multimodal-input and relaunch Chrome for on-device Gemini Nano.
  3. Open chrome://extensions, enable Developer mode, click Load unpacked, and select dist/.
